# Changelog

All notable user-facing changes are recorded here.

## 0.1.0

Initial release candidate.

- Portable local project directories backed by SQLite
- Blank project creation
- Live ingest, plots, gauges, tables, notes, video, and layouts
- Versioned NDJSON export, import, and replay controls
- `create-mcs` project generator and `mcs-platform` runtime CLI
- Project format validation, migrations, health checks, and `mcs doctor`
- Loopback-only default server with explicit remote binding acknowledgement
